# 🦉 Sudoku del Búho Sabio - Edición Leyenda PHP

Aplicación web interactiva de **Sudoku** desarrollada en PHP, HTML5, CSS3 y JavaScript vanilla. Cuenta con múltiples niveles de dificultad, lógica de validación en tiempo real, efectos de sonido sintetizados y modos de juego avanzados.

---

## ✨ Características Principales

* **6 Niveles de Dificultad:**
  1. 🥚 **Huevo Sabio** (Muy Fácil)
  2. 🐣 **Pichón Aprendiz** (Fácil)
  3. 🦉 **Cazador Nocturno** (Medio)
  4. 🌲 **Guardián del Bosque** (Difícil)
  5. 🔤 **Leyenda Ancestral** (Letras de la A a la I)
  6. 🔢🔤 **Místico Extremo** (Vocales + Números con el 0)
* **Doble Contador:** Tiempo transcurrido normal y modo Contrarreloj dinámico.
* **Sistema de Pistas:** Hasta 3 pistas por partida para revelar casillas de forma inteligente.
* **Modo Demo Infinito:** Demostración automática que resuelve tableros en bucle.
* **Efectos de Audio:** Sonidos nativos generados mediante `Web Audio API` (sin archivos de audio externos).
* **Adaptable e Imprimible:** Diseño responsive con soporte para impresión limpia en papel (`window.print()`).

## 🚀 Requisitos e Instalación

### Requisitos
* Un servidor web con soporte para **PHP 7.4+** (XAMPP, WAMP, Nginx, o el servidor integrado de PHP).
